## List of Programs

### Program 1 – Basic Single Inheritance

Demonstrates single inheritance using `Person` as the base class and `Student` as the derived class. It shows how a derived class can access members and functions inherited from the base class.

### Program 2 – Protected Member Access

Demonstrates the use of the `protected` access specifier and shows how a derived class can access a protected member of its base class.

### Program 3 – Public versus Private Inheritance

Demonstrates the difference between public and private inheritance and how inheritance mode affects the accessibility of base-class members.

### Program 4 – Multilevel Inheritance

Demonstrates multilevel inheritance using a three-level hierarchy: `Person → Employee → Manager`.

### Program 5 – Hierarchical Inheritance

Demonstrates hierarchical inheritance using `Vehicle` as a common base class for the derived classes `Car` and `Bike`.

### Program 6 – Multiple Inheritance

Demonstrates multiple inheritance using `Academic` and `Sports` as base classes and `Student` as the derived class. The program calculates the total marks from both records.

### Program 7 – Resolving Multiple-Inheritance Ambiguity

Demonstrates how ambiguity caused by two base classes having functions with the same name can be resolved using the scope-resolution operator.

### Program 8 – Constructor and Destructor Order

Demonstrates the order in which constructors and destructors are called in an inherited class hierarchy. The construction order is Base → Derived, while destruction occurs in the reverse order.

### Program 9 – Parameterized Base Constructor

Demonstrates how a derived-class constructor can initialize a parameterized constructor of its base class using an initializer list.

### Program 10 – Function Overriding

Demonstrates function overriding using a virtual function in the base class and `override` functions in derived classes.

### Program 11 – Abstract Class

Demonstrates the use of an abstract base class with a pure virtual function. The `Shape` class is implemented through derived classes such as `Rectangle` and `Circle`.

### Program 12 – Virtual Base Class and Diamond Inheritance

Demonstrates how a virtual base class can be used to solve duplicate-base ambiguity in diamond inheritance.

### Program 13 – Friend Class

Demonstrates how a friend class can access private data members of another class.

### Program 14 – Nested Class

Demonstrates how to create and use a class defined inside another class.

### Program 15 – Mini-Project: Vehicle Rental System

Implements an inheritance-based vehicle rental application using a base `Vehicle` class and derived `Car` and `Bike` classes. It demonstrates rental calculation and function overriding.

### Program 16 – Mini-Project: Employee Payroll System

## Implements an employee payroll system using an abstract base class and derived employee classes. It demonstrates inheritance, pure virtual functions, function overriding, constructors, and a polymorphic interface through a base-class reference.
